# 当年买入，持有至今 · 长期持有历史回溯动画

一个静态网页，用动画回溯在任意历史时点买入并持有至今的收益表现，覆盖 A股、美股与加密货币。

## 功能列表

- 选择买入年份，回溯持有至今的累计收益
- 支持 A股、美股、加密货币三类资产对比
- 动画式时间轴，直观呈现长期持有的复利效果
- 纯静态页面，无需后端与构建工具

## 如何本地打开

1. 下载或克隆本仓库到本地。
2. 直接用浏览器打开根目录下的 `index.html`。
3. 若浏览器限制本地文件加载，可在项目目录运行 `python -m http.server`，然后访问 `http://localhost:8000/index.html`。

- `index.html`：页面入口文件（GitHub Pages 入口）
